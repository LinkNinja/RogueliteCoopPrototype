# RogueliteCoopPrototype

A multiplayer roguelite prototype built in Unity 6 (URP) using Photon Fusion 2.0.  
I am creating this project as part of a portfolio piece with my focus on modular architecture, scalable systems, and clean multiplayer implementation.

---

## 🎯 Project Overview
This prototype explores core co‑op roguelite systems such as networked movement, player stats, combat, downed/revive mechanics, and scalable enemy encounters.  
The goal is to build a polished, modular foundation suitable for showcasing professional Unity and networking skills.

---

## ✅ Completed Milestone  
### **Milestone 1 — Networking Foundation & Core Systems Setup**

**Core achievements:**
- Unity 6 LTS project created (URP)
- Photon Fusion 2.0.11 integrated
- Clean folder structure and project architecture established
- Bootstrap → Gameplay scene flow implemented
- NetworkRunner + NetworkCallbacks fully configured
- Player prefab created with:
  - NetworkObject  
  - CharacterController  
  - NetworkTransform  
  - PlayerController (networked movement)
- Input system integrated and synced through Fusion
- Verified independent movement on Host and Client builds

Milestone 1 establishes a stable, professional-grade networking baseline for all future gameplay systems.

---

## 🚧 Current Milestone  
### **Milestone 2 — Player Systems**

Upcoming systems include:
- PlayerStats (health, damage, movement modifiers)
- PlayerCombat (basic attack system)
- Downed state

- Local hit feedback
- Health UI

This milestone introduces the first real gameplay loop and gives the player a functional identity beyond movement.
